# kv1

Landing page portofolio kv1. Situs statis (HTML, CSS, JS), tanpa build.

## Menambah karya

Edit `data/karya.js`. Salin satu blok `{ ... }`, ganti isinya, pastikan `id` unik.
Sumber karya yang didukung: `images` (slide), `src` (file video), atau `link`
(YouTube, Instagram, TikTok, Vimeo, Google Drive, Canva). Petunjuk lengkap ada di bagian atas file itu.

File gambar dan video lokal ditaruh di folder `img/` dan `video/`.

## Deploy

Import repo ini di Vercel. Framework preset: Other. Tidak perlu build command.
